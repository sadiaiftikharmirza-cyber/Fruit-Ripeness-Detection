# Fruit Ripeness Detection

## Project Overview
This project aims to detect strawberry ripeness using computer vision and deep learning.

## Objectives
- Detect strawberry ripeness from images.
- Classify strawberries into six ripeness classes.
- Train and evaluate an object detection model.

## Ripeness Classes
1. Early-Turning
2. Green
3. Late-Turning
4. Red
5. Turning
6. White

## Dataset
Dataset: Strawberry-DS (Roboflow export)

Dataset location: [https://data.mendeley.com/datasets/z6dtfdpzz8/1?utm_source=chatgpt.com]
